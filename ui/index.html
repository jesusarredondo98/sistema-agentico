        Cómo usar este asistente

        • Consulta el estado de vuelos, los datos de una reserva por su PNR y las políticas internas de AeroNova. No emite, modifica ni cancela nada.
        • Verifica antes de comprometer algo con un pasajero. Las respuestas se apoyan en documentos internos y pueden estar desactualizadas frente a una excepción concreta.
        • Cada consulta tiene un coste. Los límites existen para mantener el servicio disponible para todo el equipo.
        • Incluir el código de vuelo (AN1008) o el PNR de 6 caracteres desde el principio evita turnos de ida y vuelta.
        • No escribas credenciales, contraseñas ni datos de pago en el chat.
        • Cuando una consulta tiene datos que se pueden graficar, aparecen botones «📊 Ver gráfica» bajo la respuesta. La gráfica se dibuja solo si la pides, en tu navegador y a partir de los datos que devuelve la herramienta; no la genera la IA.
